## 🏗️ Featured Projects

### 🚘 [Sentinel Drive](https://github.com/DevTsamenyGabriel/Sentinel-Speed-Limit-Detector) — Advanced Driver Assistance System (ADAS) & Smart Cockpit
- Embedded the **Mapbox API** via PyQt6's `QWebEngineView` to overlay real-time traffic monitoring, geographic telemetry, and dynamic weather tracking.
- Engineered a hands-free voice-to-action pipeline, letting drivers trigger dashboard commands through spoken input.
- Used `QPainter` for low-latency rendering alongside **YOLOv8** and **OpenCV** for real-time speed-limit sign detection.

### 🤖 [AI Bug Fixer Agent](https://github.com/DevTsamenyGabriel/AI-bug-fixer-agent) — Autonomous Debugging & LLM Tool Calling
- Built a command-line autonomous agent that inspects a codebase, traces runtime errors, and applies patches using LLM tool/function calling in a continuous loop until the task is verifiably resolved.
- Implemented Git-aware workflows so the agent can inspect, modify, and validate changes directly against a local repository.
- Used `uv` for fast, reproducible dependency management inside a Linux/WSL development environment.

### 🧭 [Smart Navigation Dashboard](https://github.com/DevTsamenyGabriel/Smart-Navigation-Dashboard) — Voice-Controlled, Hands-Free Traffic App
- Built a fully voice-operated desktop navigation dashboard using **Whisper Flow AI** for real-time speech recognition.
- Bridged Python and JavaScript with PyQt6's `QWebChannel`, translating spoken commands directly into live map actions — pan, zoom, layer toggles.
- Designed a glassmorphism dark-mode UI focused on eliminating manual driver distraction.

### 🎙️ [Dev AI Voice Assistant](https://github.com/DevTsamenyGabriel/Dev-AI-Voice-Assistant) — Live Speech-to-Text & Spoken Chatbot
- Built a CLI chatbot that streams LLM response tokens to two consumers simultaneously — a live text renderer and a text-to-speech engine — keeping spoken and written output in sync in real time.
- Structured the backend to be model-agnostic, so custom LLM backends or offline models can be swapped in with minimal changes.

### 🏦 [Accessible ATM Simulator](https://github.com/DevTsamenyGabriel/Accessible-ATM-Simulator) — Voice-Enabled Accessibility Banking System
- Built a VB.NET banking simulation with integrated text-to-speech that audibly confirms balances, deposits, and withdrawals — enabling independent use for visually impaired users.
- Paired every transaction path with dual visual and audio feedback plus input validation to reduce user error.

### 💳 Zero-API Automated Payment Confirmation System — Full-Stack Automation
- Designed a lightweight payment verification backend for a context with no formal payment gateway integration available.
- Built a self-hosted automation flow that parses incoming SMS transactional alerts and triggers order fulfillment automatically.
- A case study in solving a real infrastructure gap with pure software engineering rather than waiting on external tooling.

### 🔒 [Luhn-16 Card Validator](https://github.com/DevTsamenyGabriel) — Algorithms & Data Integrity
- Built a lightweight 16-digit card validation engine implementing the Luhn (Mod 10) algorithm.
- Focused on string manipulation, input sanitization, and the verification logic that underpins fintech data integrity.

### 🎯 [Object-Tracker-ML](https://github.com/DevTsamenyGabriel/Object-Tracker-ML) — Interactive Single-Object Video Tracker
- Built a real-time tracking tool where the user drags a bounding box around a target on the first frame, and OpenCV's **MIL tracker** follows it through the rest of the video.
- Implemented target-loss detection, flagging the moment tracking fails instead of silently drawing a stale box.
- A hands-on demonstration of the difference between detection (finding objects) and tracking (following one specific object over time).
